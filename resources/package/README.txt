速看CAD 1.0.4
================

Supported systems
- Windows x64
- macOS Intel x64 and Apple Silicon arm64

Main features
- DWG/DXF model-space and paper-space layouts via LibreDWG/libdxfrw
- CAD object snaps, orthographic mode, grid, window zoom
- Vector dimensions, area/perimeter/circle measurements
- Automatic local annotation recovery
- Recent drawing thumbnails

Data and privacy
- Drawings are processed locally and are not uploaded.
- Measurement autosaves are stored next to the drawing using
  <drawing>.cadlens.autosave.json.
- Calibration and recent-drawing caches are stored in the current user's
  application settings and cache folders.

Third-party components
- Qt 6.8.3
- LibreDWG
- libdxfrw
- GNU libiconv
- Osifont and Noto Sans CJK SC

See the project third_party folders for complete license texts.
